# 리눅스 마스터 클래스 — 커리큘럼 로드맵 & 자습서

리눅스 강의(7섹션 · 65챕터)를 위한 **웹 학습 자료 2종**입니다. 둘 다 빌드나 서버 없이 브라우저로 바로 열리는 단일 HTML 파일입니다.

| 파일 | 용도 | 크기 |
|---|---|---|
| **`index.html`** | 커리큘럼 로드맵 — 전체 과정 구조를 트리/리스트로 탐색 | 80KB |
| **`study.html`** | 학습 자습서 — 챕터별 본문·실습·퀴즈를 혼자 읽고 따라가는 교재 | 3.2MB |

두 페이지는 상단 바에서 서로 이동할 수 있습니다.

## 바로 사용하기

```bash
git clone https://github.com/HackSung/linux-lecture-roadmap.git
cd linux-lecture-roadmap
open index.html   # macOS  (Linux: xdg-open, Windows: start)
```

외부 CDN·빌드 도구·서버가 필요 없습니다. 웹폰트(Google Fonts)만 네트워크에서 가져오고, 오프라인에서도 시스템 폰트로 정상 동작합니다.

## 로드맵 (`index.html`)

강의 전체 구조를 한눈에 보는 페이지입니다.

- **트리 뷰** — 섹션 → 챕터 계층을 펼쳐보며 탐색
- **리스트 뷰** — 65챕터를 평면 목록으로 훑어보기
- **퀴즈 뷰** — 24문항으로 이해도 점검
- **검색** — 챕터 제목·학습 주제 키워드 검색
- **챕터 상세 패널** — 챕터를 누르면 다룰 내용이 우측 패널에 열림
- 다크/라이트 테마 전환, 실습 챕터 색상 구분

## 자습서 (`study.html`)

강의를 듣지 않고도 혼자 학습할 수 있도록 만든 교재입니다. 65챕터 · 콘텐츠 블록 1,622개 · 약 50만 자.

**학습 기능**

- **진도 관리** — 챕터별 '학습 완료' 체크, 진행률 표시. 브라우저(`localStorage`)에 저장되어 다시 열어도 유지
- **명령어 복사** — 코드 블록마다 개별/전체 복사 버튼
- **실습 카드** — 실습 절차를 단계별로 제시하고 각 단계의 예상 결과를 명시
- **인라인 퀴즈** — 해당 챕터 끝에서 바로 풀고 해설 확인
- **치트시트** — 강의 전체 명령어 147개를 한 페이지에 모으고, 각 명령어를 배운 챕터로 점프
- **전체 검색** — 본문·비교표·명령어·실습 단계까지 전문 검색 (`/` 키)
- **키보드 이동** — `←` `→` 로 이전/다음 챕터

**콘텐츠 구성** — 각 챕터는 학습 목표로 시작해 아래 블록들이 흐름을 이루고, 핵심 정리로 끝납니다.

| 블록 | 역할 |
|---|---|
| 개념 설명 | 원리를 글로 설명 |
| 비유 | 추상적 개념을 익숙한 대상에 견주어 설명 |
| 비교표 | 옵션·명령어·개념 차이를 표로 정리 |
| 터미널 예시 | 실행 명령과 실제 출력 |
| 실습 카드 | 단계별 실습 절차와 예상 결과 |
| 흔한 실수 | 초보자가 자주 겪는 오류와 해결법 |
| 실무 팁 | 현업에서 쓰이는 맥락 |
| 생각해보기 | 스스로 답해본 뒤 펼쳐보는 질문 |

## 저장소 구성

```
index.html               로드맵 (데이터 내장, 단독 실행)
study.html               자습서 (데이터 내장, 단독 실행)
study_template.html      자습서 UI 템플릿 (빌드 입력)

study_content.json       자습서 본문 콘텐츠 (65챕터)
data.json                커리큘럼 구조 (섹션·챕터·학습주제)
data.min.json            data.json 압축본
quiz_data.json           퀴즈 24문항

build_study.py           study_template + 콘텐츠 → study.html 생성
merge_study_content.py   섹션별 JSON 병합 및 스키마 검증
compare_enrich.py        콘텐츠 분량 전후 비교 리포트
```

`index.html`과 `study.html`은 데이터를 파일 안에 내장하고 있어 **JSON 파일 없이도 단독으로 동작**합니다. JSON은 콘텐츠를 수정해 페이지를 다시 생성할 때 쓰는 원본입니다.

## 콘텐츠 수정하기

자습서 내용을 고칠 때:

```bash
# 1) study_content.json 에서 해당 챕터 수정
# 2) 재생성
python3 build_study.py
```

UI(레이아웃·스타일·동작)를 고칠 때는 `study_template.html`을 수정한 뒤 같은 명령으로 재생성합니다. `study.html`을 직접 고치면 다음 빌드에서 덮어써지니 주의하세요.

섹션별로 나뉜 JSON을 합쳐서 쓰는 경우:

```bash
python3 merge_study_content.py <섹션JSON_디렉터리>   # 스키마 검증 + 병합
python3 build_study.py
```

`compare_enrich.py`는 콘텐츠를 크게 손볼 때 분량 변화를 확인하는 보조 도구입니다. 수정 전 `study_content.json`을 `study_content_v1.json`으로 복사해두면, 수정 후 챕터별 증감을 표로 비교해줍니다. 기준 파일이 없으면 비교를 건너뜁니다.

`merge_study_content.py`는 병합과 함께 다음을 검사합니다.

- 섹션·챕터 번호가 기준 목차와 일치하는지
- 블록별 필수 필드 누락, 표의 헤더-행 칸수 불일치
- 이전 버전 대비 분량이 줄어든 챕터(의도치 않은 내용 유실 감지)

## 브라우저 지원

최신 Chrome · Safari · Firefox · Edge. 모바일에서도 목차가 접히는 반응형 레이아웃으로 동작합니다.

진도와 퀴즈 기록은 브라우저별 `localStorage`에 저장되므로 기기·브라우저 간에 공유되지 않습니다. 시크릿 모드에서는 창을 닫으면 사라집니다.
